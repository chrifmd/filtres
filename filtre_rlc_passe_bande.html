Aperçu théorique — régime sinusoïdal

Loi des mailles du circuit RLC série (résistance r de la bobine négligée devant R₀, comme dans la simulation) :

uE(t) = uR(t) + uL(t) + uC(t)

Le même courant i(t) traverse R₀, L et C : c'est la référence des phases (vecteur horizontal). Avec ω = 2πN, et la sortie uS = uR :

  • UR = R₀·Im : en phase avec i ;
  • UL = Lω·Im : en avance de 90° sur i ;
  • UC = Im / (Cω) : en retard de 90° sur i.

UL et UC sont opposés : leur somme vaut UL − UC, perpendiculaire à UR (Pythagore) :

UE² = UR² + (UL − UC)²

Transmittance :

T = US/UE = R₀ / √(R₀² + (Lω − 1/(Cω))²)
REPRÉSENTATION DE FRESNEL UR = US UL UC UE

Déphasage φ (d'après Fresnel)

φ est le déphasage de uS par rapport à uE : c'est l'opposé de l'angle entre UE et la référence i. Dans le triangle rectangle :

tan φ = (UC − UL) / UR = (1/(Cω) − Lω) / R₀

Avec N0 = 1 / (2π√(LC)) et Q = (1/R₀)√(L/C) :

tan φ = Q · (N0/N − N/N0)
cos φ = UR / UE = T
  • N < N0 : UC > UL, circuit capacitif, φ > 0 (uS en avance), φ → +90° quand N → 0 ;
  • N = N0 : UL = UC se compensent, UE = UR, φ = 0 ;
  • N > N0 : UL > UC, circuit inductif, φ < 0 (uS en retard), φ → −90° quand N → ∞.

Bande passante à −3 dB

À la résonance N = N0, Tmax = 1 (0 dB). La bande passante est l'ensemble des fréquences pour lesquelles T ≥ 1/√2, c'est-à-dire UR ≥ UE/√2. D'après Fresnel :

T = 1 / √(1 + Q²(N/N0 − N0/N)²)
T ≥ 1/√2 ⇔ |UL − UC| ≤ UR ⇔ |tan φ| ≤ 1

Aux fréquences de coupure N1 et N2 : |UL − UC| = UR, UE = UR√2 et φ = ±45°. Bande passante : [ N1 ; N2 ]

N2 − N1 = R₀/(2πL) = N0/Q
N1 · N2 = N0²

Plus Q est grand, plus la bande est étroite (filtre sélectif). À N0, il y a surtension : UL = UC = Q·UE.
