Aperçu théorique — régime sinusoïdal linéaire

L'AOP est idéal et fonctionne en régime linéaire : e = 0 et i⁻ = i⁺ = 0. Le point A est donc une masse virtuelle (VA = 0). Loi des nœuds en A :

i0(t) = i1(t) + iC(t)

Amplitudes, avec ω = 2πN :

  • I0 = UE / R0, en phase avec uE ;
  • I1 = US / R1, en phase avec uS au signe près : c'est la référence des phases ;
  • IC = C₁ω·US, en avance de 90° sur I1.

Les vecteurs I1 et IC étant perpendiculaires (Pythagore) :

I0² = I1² + IC²

Transmittance et gain, avec T0 = R1/R0 :

T = US/UE = T0 / √(1 + (R₁C₁ω)²)
G = G0 − 10·log(1 + (N/Nc)²)
REPRÉSENTATION DE FRESNEL (COURANTS) I1 IC I0

Déphasage φ (d'après Fresnel)

L'angle α entre les vecteurs I0 et I1 est le retard introduit par la cellule R₁C₁ entre uS et uE. Dans le triangle rectangle :

tan α = IC / I1 = R₁C₁ω = N / Nc

Le montage étant inverseur, il s'ajoute un déphasage de −180° :

φ(N) = −180° − arctan(N / Nc)
  • N ≪ Nc : φ → −180° (simple inversion) ;
  • N = Nc : φ = −225° (α = 45°) ;
  • N ≫ Nc : φ → −270° (retard maximal du 1ᵉʳ ordre).

Bande passante à −3 dB

C'est l'ensemble des fréquences N pour lesquelles T ≥ T0/√2, soit G ≥ G0 − 3 dB, avec G0 = 20·log(R1/R0). D'après Fresnel :

T ≥ T0/√2 ⇔ N/Nc ≤ 1 ⇔ N ≤ Nc

Bande passante : [ 0 ; Nc ] avec Nc = 1 / (2πR₁C₁). Au-delà de Nc, le gain décroît de 20 dB/décade. Pour N = Nc : IC = I1 = I0/√2 et α = 45°.
