# Simulateurs de filtres électroniques

Application web statique en français pour explorer quatre filtres analogiques :

- filtre RC passe-bas ;
- filtre RC passe-haut ;
- filtre RLC série passe-bande ;
- filtre passe-bas actif à amplificateur opérationnel.

Chaque simulateur calcule la réponse fréquentielle, affiche les diagrammes de Bode
et visualise le signal d'entrée et le signal filtré dans un oscilloscope.

## Utilisation

Ouvrir `index.html` dans un navigateur moderne, puis choisir un montage. Aucun
serveur, paquet ou dépendance externe n'est nécessaire : les pages et leurs
calculs JavaScript sont autonomes.
