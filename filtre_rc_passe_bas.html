Aperçu théorique — régime sinusoïdal

Loi des mailles appliquée au circuit RC passe-bas :

uE(t) = uR(t) + uS(t)

On prend uS comme référence des phases (vecteur horizontal), avec ω = 2πN :

  • le courant i = C·duS/dt est en avance de 90° sur uS : Im = Cω·US ;
  • uR = R·i est en phase avec i : UR = RCω·US, vecteur vertical ;
  • uE : somme vectorielle de US et UR.

US et UR étant perpendiculaires (théorème de Pythagore) :

UE² = US² + UR²
REPRÉSENTATION DE FRESNEL
US UR UE

Déphasage φ (d'après Fresnel)

L'angle entre les vecteurs UE et US vaut |φ| : c'est le déphasage de uS par rapport à uE. Dans le triangle rectangle :

tan |φ| = UR / US = RCω

Avec Nc = 1 / (2πRC) :

tan |φ| = N / Nc
cos φ = US / UE = T

φ < 0 : uS est en retard sur uE. φ tend vers 0° quand N → 0 et vers −90° quand N → ∞ ; φ = −45° pour N = Nc.

À l'oscilloscope, si τ est le décalage temporel entre les deux courbes : |φ| = 360° · N · τ

Bande passante à −3 dB

C'est l'ensemble des fréquences N pour lesquelles T ≥ Tmax/√2, soit G ≥ Gmax − 3 dB. Ici Tmax = 1 (N → 0). D'après Fresnel :

T = US / UE = 1 / √(1 + (N/Nc)²)
T ≥ 1/√2 ⇔ N/Nc ≤ 1 ⇔ N ≤ Nc

Bande passante : [ 0 ; Nc ] avec Nc = 1 / (2πRC). Pour N = Nc : UR = US = UE/√2 et |φ| = 45°.
